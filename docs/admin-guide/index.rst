===============================================
Twake Directory Manager — Administrator’s Guide
===============================================

This guide is a hands-on introduction to Twake Directory Manager, the
administration console of the company directory. It is written for **global
administrators**, who manage the whole directory, and for **local
administrators**, who manage one or more branches of the organization.

It describes the console as it appears with the Twake schemas shipped by
default, behind OpenID Connect authentication (single sign-on and sign-out).
